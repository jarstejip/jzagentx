# 🎨 JZAGENTIC AI Designer - Official Figma Plugin

Plugin resmi **JZAGENTIC** untuk Figma & FigJam. Menghubungkan langsung AI Agent multi-model (Claude 3.7 Sonnet, GPT-4o, Gemini 2.0 Flash, DeepSeek-V3) langsung ke Canvas Figma Anda.

---

## 🚀 Cara Memasang di Figma (Hanya 15 Detik):

1. **Buka Aplikasi Figma** (Desktop App atau di Browser: https://www.figma.com).
2. Buka salah satu file desain atau buat file baru.
3. Klik menu **Figma** (logo Figma di pojok kiri atas).
4. Pilih **Plugins** → **Development** → **Import plugin from manifest...**.
5. Pilih file `manifest.json` yang berada di folder:
   ```
   c:\jzagentic\figma-plugin\manifest.json
   ```
6. **Selesai!** Plugin **JZAGENTIC AI Designer** sekarang langsung muncul di list plugin development Anda.

---

## ⚡ Cara Menggunakan:

1. Di canvas Figma, tekan `Shift + I` atau klik kanan → **Plugins** → **Development** → **JZAGENTIC AI Designer**.
2. Jendela plugin JZAGENTIC akan terbuka.
3. Pilih model AI yang ingin Anda gunakan (Claude 3.7, GPT-4o, Gemini 2.0, dll.).
4. Pilih salah satu **Template Cepat** (Hero Section, Pricing Table, Mobile Login, dll.) ATAU ketik prompt bebas Anda sendiri.
5. Klik **"✨ Generate ke Canvas Figma"**.
6. AI akan otomatis merakit Frame, Auto-Layout, Teks, Warna, dan Tombol langsung di tengah canvas Figma Anda!
