🚀 Cara Memasang di Figma (Hanya 15 Detik)
1

Unduh & Ekstrak File Plugin

Buka website https://jzagentx.my.id > klik tombol "🎨 Figma AI" di navbar atas untuk mendownload file jzagentic-figma-plugin.zip, lalu ekstrak filenya ke komputer Anda.

2

Buka Menu Import Manifest di Figma

Buka aplikasi Figma (Desktop atau Browser) > Buka file desain Anda > Klik Menu Figma (logo kiri atas) > Pilih Plugins > Development > Klik "Import plugin from manifest...".

3

Pilih File manifest.json

Pilih file manifest.json dari folder hasil ekstrak tadi. Plugin JZAGENTIC AI Designer langsung terpasang dan tersimpan di Figma Anda!

🎨 Cara Mendesain Menggunakan AI di Canvas
A

Buka Plugin JZAGENTIC

Di dalam canvas Figma, tekan shortcut Shift + I > pilih tab Plugins > klik JZAGENTIC AI Designer (atau klik kanan di canvas > Plugins > Development > JZAGENTIC AI Designer).

B

Pilih Model AI Favorit & Masukkan Instruksi

Pilih model AI di dropdown (Claude, GPT, Gemini, DeepSeek). Gunakan Template Cepat (Hero Section, Pricing, Mobile Login, Stats) atau ketik prompt kustom sesuai ide Anda.

C

Klik "Generate ke Canvas Figma"

AI akan langsung merakit Frame, Auto-Layout, Teks, Warna, dan Tombol otomatis tepat di tengah layar canvas Figma Anda!
